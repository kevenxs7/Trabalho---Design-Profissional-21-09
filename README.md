## 1. Introdução e Análise de Mercado: Engenharia de Dados

### Panorama do Mercado
A Engenharia de Dados é uma das disciplinas de Tecnologia da Informação de maior crescimento e demanda no mercado global e brasileiro. Com o avanço da Inteligência Artificial e do ecossistema de *Big Data*, as organizações necessitam de infraestruturas robustas, escaláveis e confiáveis para coletar, armazenar, transformar e disponibilizar dados. A remuneração média para profissionais da área varia entre R$ 4.500,00 (nível Júnior/Estágio) e supera R$ 15.000,00 para perfis Seniores e Especialistas em plataformas Cloud.

### Mapeamento de Vagas
Com base em buscas recentes em plataformas de recrutamento como LinkedIn, Glassdoor e Indeed, identificam-se duas faixas de atuação principais para iniciantes na área:

1. **Estágio em Engenharia / Análise de Dados**
   * *Requisitos:* Cursando Análise e Desenvolvimento de Sistemas, Ciência da Computação ou correlatas; conhecimentos em lógica de programação (Python ou Java), SQL básico a intermediário e noções de Git/GitHub.
   * *Responsabilidades:* Auxiliar na sustentação de *pipelines* de dados, escrita de rotinas de consulta SQL e documentação de processos.

2. **Engenheiro(a) de Dados Júnior**
   * *Requisitos:* Superior completo ou em fase final; domínio de Python e SQL; experiência com bancos de dados relacionais e não-relacionais; noções de ecossistemas Cloud (AWS, Azure ou GCP) e ferramentas de ETL/ELT (Airflow, PySpark).
   * *Responsabilidades:* Desenvolver e manter fluxos de integração de dados, garantir a qualidade dos dados e otimizar rotinas de banco de dados.

### Mapeamento de Competências

| Categoria | Competências (Skills) Exigidas |
| :--- | :--- |
| **Hard Skills** | Python, SQL (avançado), Modelagem de Banco de Dados (Relacional e NoSQL), Git/GitHub, Conceitos de ETL/ELT, Plataformas Cloud (AWS/Azure/GCP), PySpark e Linux básico. |
| **Soft Skills** | Resolução de problemas complexos, Comunicação assertiva, Trabalho em equipe, Capacidade de autoaprendizado e Visão analítica do negócio. |

## 3. Conclusão: Análise de Gaps e Plano de Ação

### Análise Conjunta e Comparação com o Mercado
Ao cruzar os perfis atuais dos integrantes com o mapeamento de mercado para a área de **Engenharia de Dados**, observa-se que o grupo possui uma sólida base teórica e de lógica de programação fornecida pelo curso de Análise e Desenvolvimento de Sistemas, com familiaridade inicial na linguagem Python.

### Identificação de Gaps (Lacunas)
1. **Falta de Projetos Práticos Focados em Dados:** Grande parte dos repositórios atuais no GitHub reflete exercícios acadêmicos gerais, faltando projetos específicos de *ETL/ELT*, raspagem de dados ou manipulação com Pandas/PySpark.
2. **Posicionamento nos Perfis (LinkedIn/GitHub):** Os perfis ainda não utilizam todo o potencial das palavras-chave buscadas pelos recrutadores da área de dados (ex: SQL Avançado, Airflow, Modelagem Dimensional).
3. **Certificações e Nuvem:** Ausência de certificações de entrada em Cloud Computing (AWS/Azure/GCP), que são diferenciais competitivos para vagas de entrada.

### Plano de Ação do Grupo
Para eliminar essas lacunas até o término do curso, o grupo estabelece o seguinte plano de ação:

* **Mês 1 a 3:** Criar um repositório compartilhado de projetos práticos contendo rotinas de extração, transformação e carga de dados (ETL) utilizando Python e PostgreSQL.
* **Mês 4 a 6:** Otimizar os perfis do LinkedIn com palavras-chave estratégicas da área de Engenharia de Dados e buscar engajamento em comunidades técnicas (interagindo em posts e compartilhando aprendizados).
* **Mês 7 a 12:** Iniciar estudos preparatórios para uma certificação de nível *Cloud Practitioner* (AWS) ou *Azure Fundamentals* (AZ-900) e candidatar-se ativamente a vagas de estágio e nível Júnior na área.
